# 个人理财记账系统

命令行交互式个人财务管理工具，支持收支记录管理、分类筛选、月度统计和图表可视化。

## 功能

- **收支记录管理** — 添加、查看、修改、删除收入/支出记录
- **按月份筛选统计** — 查看各月收入、支出、结余汇总
- **按分类筛选统计** — 按收入/支出分类（工资、餐饮、交通等）汇总
- **财务概览** — 累计收支结余概览 + 分类统计柱状图（ASCII）
- **图表可视化** — 饼图（分类占比）、柱状图（收支对比）、折线图（月度趋势）
- **用户认证** — 简易登录保护

## 项目结构

```
├── main.py        # 主程序入口，命令行交互菜单
├── finance.py     # 核心功能：记录的增删改查与数据持久化
├── chart.py       # 图表绘制（matplotlib）：饼图、柱状图、趋势折线图
├── utils.py       # 工具函数：数据校验、格式化、表格打印
└── data.json      # 数据存储文件（JSON 格式）
```

## 快速开始

### 环境要求

- Python 3.8+
- （可选）matplotlib — 用于图表功能

### 安装依赖

```bash
pip install matplotlib
```

> matplotlib 为可选依赖，未安装时图表功能不可用，其他功能正常运行。

### 运行

```bash
python main.py
```

## 使用说明

启动后进入主菜单，输入对应数字执行操作：

| 选项 | 功能 |
|------|------|
| 1. 添加收支记录 | 选择收入/支出 → 分类 → 输入金额、日期、备注 |
| 2. 查看所有记录 | 表格形式展示全部记录，按日期降序排列 |
| 3. 按月份筛选统计 | 选择月份查看该月收入/支出/结余汇总 |
| 4. 按分类筛选统计 | 选择分类查看该类别下所有记录及合计 |
| 5. 修改记录 | 按 ID 查找并修改记录的任意字段 |
| 6. 删除记录 | 按 ID 删除记录（二次确认） |
| 7. 财务统计概览 | 累计收支结余 + 各分类柱状图（ASCII） |
| 8. 图表绘制 | 饼图、柱状图、月度趋势折线图 |

在任意输入环节输入 `q` 可取消当前操作。

## 数据存储

所有数据存储在项目目录下的 `data.json` 文件中。首次运行时会自动创建包含默认用户的数据文件。

## 图表功能

图表功能依赖 matplotlib，安装后可使用：

- **支出/收入分类饼图** — 按分类查看金额占比
- **收支分类柱状图** — 收入与支出各类目对比
- **月度收支趋势折线图** — 展示各月收入、支出、结余变化趋势

图表会弹出独立窗口显示，关闭窗口后返回菜单。
